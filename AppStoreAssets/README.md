# App Store Assets

This directory contains self-authored demo pages and screenshots for the
TriColumns App Store product page. All names, organizations, posts, metrics,
and activity shown in the demo are fictional. The demo does not reproduce the
interface, trademarks, or user content of any third-party service.

All screenshots are captured from the shipping TriColumns app at 1440 x 900.
App Preview video is intentionally omitted because it is optional.
